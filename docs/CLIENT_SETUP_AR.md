# رابط إعداد المتجر

بعد إنشاء متجر، ينشئ النظام تلقائيًا حساب إعداد مستقلًا بعضوية ذلك المتجر فقط. تعرض صفحة إدارة المتجر بطاقة «رابط إعداد العميل» لنسخ الرابط أو فتح واتساب برسالة جاهزة. لا تُرسل الرسالة دون ضغط المالك زر الإرسال في واتساب.

الرابط يفتح لوحة إعداد البيانات والصور والتصميم والخطوط والأقسام والمنتجات والصفحات والتواصل والبنوك وSEO والنطاق. الخطوة الأخيرة «انشر المتجر» تفتح واتساب المنصة بالنص «انتهيت من إعداد المتجر» مع اسم المتجر ورابطه؛ لا تغيّر حالة النشر تلقائيًا. يبقى تسليم المتجر ونشره تحت إدارة مالك المنصة.

## متطلبات الإنتاج قبل النشر

1. طبّق `supabase/migrations/0014_client_setup_access.sql` باستخدام SQL Editor في مشروع Supabase. ينشئ جدول وصول خاصًا، ويوسع إعدادات عضو المتجر، ويحمي رابط المطور، ويوقف الوصول إلى سجل النشاط التاريخي.
2. تأكد من وجود `SUPABASE_SECRET_KEY` أو `SUPABASE_SERVICE_ROLE_KEY` في بيئة الخادم فقط. يستخدمه النظام لإنشاء حساب إعداد محدود العضوية؛ لا يُرسل المفتاح إلى المتصفح.
3. اضبط رقم واتساب المنصة من إعدادات الموقع. ثم انشر إصدار الكود.

إذا تعذر تجهيز الرابط بسبب إعدادات الإنتاج، يظل المتجر محفوظًا؛ يمكن إعادة تجهيز الرابط من بطاقته دون إنشاء متجر مكرر. عند عدم ضبط رقم الواتساب يُعرض سبب عدم توفر زر النشر بدل فتح رابط معطوب.

## الوصول والخصوصية

- كل رابط يحمل بيانات دخول عشوائية لحساب إعداد مستقل بعضوية متجر واحد. لا يعتمد على بريد العميل، ولا يغيّر كلمة مرور حساب موجود.
- بيانات الدخول محفوظة في جدول خاص لا يقرؤه الزوار أو الحسابات العادية. تظهر في الرابط ضمن fragment الذي لا يُرسل إلى خادم الويب أو معاينات واتساب. يمسحه المتصفح فور القراءة، ثم يسجل الدخول عبر POST وتُستخدم جلسة التطبيق المعتادة وRLS.
- الرابط قابل لإعادة الاستخدام؛ يُرسل لصاحب المتجر فقط. إلغاء الحساب المخصص من Supabase Auth يبطل الدخول به.
- اسم المنصة ورابطها في شريط حقوق التطوير ثابتان في واجهة المتجر، وحقل رابط المطور ممنوع في API العميل ومحمي كذلك بمحفز قاعدة البيانات.
- أزيلت صفحات وتبويبات وواجهات برمجة وعمليات تسجيل النشاط. يحتفظ الترحيل بالبيانات التاريخية دون عرضها أو الكتابة إليها.

## التحقق

`npm run build`، و`node scripts/verify-rls.mjs`، و`node scripts/verify-local-flows.mjs`.
