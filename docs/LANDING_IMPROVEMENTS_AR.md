# تحسين الصفحة العامة لمعون

التغيير يوضح فائدة المتجر، ويعرض الباقات ومزاياها ومدة سعرها مباشرة، ويربط طلب واتساب بالباقة أو نموذج المتجر المختار. لا يغيّر أسعار قاعدة البيانات ولا بيانات متاجر العملاء أو SQLite، ولا يحتاج ترحيل قاعدة بيانات.

## التعديلات

- نص الغلاف قبل الصورة على الجوال، وأزرار أكبر ومسافات مناسبة لشريط التنقل الثابت.
- تحديث النصوص التسويقية القديمة المعروفة عند العرض، مع الحفاظ على النصوص المخصصة الأخرى.
- إزالة عدادات التسويق القديمة التي لا تثبت عدد العملاء أو وقت التسليم.
- توحيد أسماء باقات الانطلاقة والراحة والتاجر عند العرض، والإبقاء على أسعارها المخزّنة.
- حذف إعلان بوابة الدفع بالبطاقات من مزايا الباقات: مسار الدفع الموجود يعتمد على واتساب والتحويل البنكي.
- تقليل الوعود المبالغ فيها بشأن رفع المنتجات بلا قيود، معالجة الأعطال فورًا، الأداء مع آلاف الزوار، وضمان نتائج البحث.
- تمييز نماذج البذور التجريبية المعروفة، وإضافة «جرّب المتجر» و«أبي متجر مثل هذا» دون تغيير نمط العرض التلقائي.
- إضافة خطوات الحصول على المتجر وقسم الاشتراك والدعم واسم مقدّم الخدمة ورابط التواصل الرسمي.
- تحديث وصف SEO القديم الذي يعلن 499 ريالًا دفعة واحدة، مع الحفاظ على وصف SEO مخصص مختلف.
- تحسين إمكانية الوصول إلى القائمة والأسئلة الشائعة، وتجنب روابط الأقسام المخفية أو الفارغة.

## محتوى يجب أن يحدده المالك

من **الإدارة ← المحتوى ← الاشتراك والدعم** يمكن تحرير مدة السعر والرسوم وشروط الإلغاء والاسترداد ونطاق الدعم وبيانات مقدّم الخدمة. الافتراضي يطلب تأكيد هذه الشروط قبل الاشتراك؛ لا ينشئ سياسة استرداد أو يختلق سجلًا تجاريًا أو وقت استجابة مضمونًا. استبدله بشروطك الفعلية وبيانات الجهة الموثقة عندما تحددها.

الباقات **شهرية** افتراضيًا وفق نموذج الخدمة الحالي. إن تغيرت مدة التسعير، عدّل خانة مدة السعر ونص الرسوم معًا. يتيح وسم `نموذج تجريبي` في وسوم معرض الأعمال تمييز نماذج إضافية غير النماذج المزروعة أصلًا.

## التحقق

```sh
npm run test:landing
npx tsc --noEmit
npm run build
npm run cf-build
```

فحص `test:landing` يتحقق من توافق الإعدادات القديمة، الحفاظ على تخصيصات المالك والأسعار دون تعديل المدخلات، ترتيب الأقسام الجديدة، حذف الادعاءات المحددة، علامات النماذج التجريبية، تصحيح وصف SEO، وترميز رسائل واتساب العربية.

لم يُجرَ فحص بصري في متصفح داخل هذه البيئة؛ يجب مراجعة الواجهة على الجوال بعد نشر فرع التعديلات. نشر الموقع الحالي يظل عبر مشروع Cloudflare القائم.
